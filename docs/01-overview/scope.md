# Scope

## In scope

- Single-user local desktop application (JavaFX).
- Local authentication (login required).
- Seeded movies, theatres, shows, and seats.
- Row/column seat grid; duplicate-seat prevention (service validation + DB constraint).
- Ticket total calculation; on-screen booking confirmation with booking ID.
- SQLite persistence; JUnit 5 tests; full documentation set.

## Out of scope (confirmed)

- Multi-user / networked deployment.
- Payment processing.
- VIP seat tiers.
- Admin management UI (initially).
- Real ticket printing/e-ticket files — confirmation is on-screen only.
