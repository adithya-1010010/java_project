# Roadmap

```text
Phase 01  Foundation (Maven/JavaFX/JUnit/SQLite deps, docs skeleton)     ← done
Phase 02  Domain model + OOP design + unit tests
Phase 03  SQLite schema, seed data, repository layer
Phase 04  Authentication (login)
Phase 05  Movie + theatre + show modules (browse)
Phase 06  Seat grid + availability
Phase 07  Booking workflow + ticket calculation (transactional)
Phase 08  Confirmation / ticket display
Phase 09  End-to-end integration and validation
Phase 10  Quality, polish, documentation, final acceptance
```

No phase starts until the previous one is tested, documented, committed, and pushed.
