- Clean and understandable; not over-engineered.

1. Login
2. Home/dashboard
3. Movie listing
4. Show selection
5. Seat selection (row/column grid)
6. Customer details / booking details
7. Booking summary

Each screen plan documents purpose, controls, inputs, validation, navigation, controller, service calls, and loaded data — see [screens.md](screens.md) and [screen-flow.md](screen-flow.md).
