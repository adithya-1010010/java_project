# Development Workflow

1. Read `memory.md` and current phase document.
2. Implement only the current phase.
3. Run automated tests (`mvn test`).
4. Manual verification.
5. Review the diff.
6. Update documentation and `memory.md`.
7. Final build/test.
8. Commit with the phase message from `implementation-plan.md`.
9. Push; verify; **stop** (no next phase automatically).
