# Booking Flow

End-to-end booking journey from movie selection to persisted booking.

1. User selects a movie → shows for that movie are listed.
2. User selects a show → seat grid loads.
3. User selects available seats → proceeds to customer details.
4. Customer details validated → booking summary with total cost.
5. Seat availability re-checked → booking persisted in a transaction → booking ID generated → confirmation displayed.

Detail for seats: [seat-booking-flow.md](seat-booking-flow.md). Detail for confirmation: [confirmation-flow.md](confirmation-flow.md).
